# ell0.uz

The source for [ell0.uz](https://ell0.uz), a personal site and portfolio.

## About

This is a small, dependency-free static website. The page, styles, and interactive effects are
contained in `index.html`; fonts, the favicon, and the social preview image are stored alongside it.

## Preview

Open `index.html` in a browser, or serve this directory with any static file server.

## Formatting

The repository includes a Prettier configuration. Check or format the HTML with:

```sh
npx prettier --check index.html
npx prettier --write index.html
```
